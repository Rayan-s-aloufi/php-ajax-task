# تطبيق إدارة المستخدمين مع PHP و MySQL و AJAX

تطبيق ويب متكامل يتيح إدارة قائمة المستخدمين وتحديث الحالات مباشرة بدون إعادة تحميل الصفحة.

## 🌟 المميزات
- إضافة مستخدم جديد (الاسم والعمر).
- العرض المباشر للبيانات المخزنة في قاعدة البيانات.
- تحديث حالة المستخدم (Toggle) باستخدام AJAX / Fetch API.
- تصميم متجاوب وأنيق باللغة العربية.

## 📂 ملفات المشروع
- `index.php`: الواجهة الرئيسية والتفاعلية.
- `api.php`: معالجة الطلبات الخلفية (AJAX Handler).
- `db.php`: إعدادات الاتصال بقاعدة البيانات.
- `schema.sql`: استعلام إعداد قاعدة البيانات.
